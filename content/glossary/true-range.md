True range is the largest of three measures of a bar's movement: its high minus low, the high minus the previous close, and the previous close minus the low.

## Explained

J. Welles Wilder created true range so that gaps are counted. A plain high-minus-low range ignores a gap between yesterday's close and today's open, so it can understate how far price really moved.

True range is the raw input to the [Average True Range](/atr/) (ATR), which averages it over a set number of bars, usually 14. It is also used by volatility tools such as [Keltner Channels](/keltner-channels/) and the [Supertrend](/supertrend/), and by the [ATR stop](/atr-stop/). It measures size only, never direction.

## Example

Yesterday closed at 100. Today the high is 106 and the low is 103. High minus low is 3. High minus previous close is 6. Previous close minus low is -3, so its size is 3. The largest is 6, so today's true range is 6, which captures the gap up.
